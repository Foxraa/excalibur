## À retenir

Dans un groupe nominal, **le nom commande** : le **déterminant** et l'**adjectif** prennent son **genre** (masculin/féminin) et son **nombre** (singulier/pluriel).

> *un petit chat noir* → *une petit**e** chatt**e** noir**e*** → *des petit**s** chat**s** noir**s*** → *des petit**es** chatt**es** noir**es***

```schema phrase
[des|dét.] [petites|adj. : f. pl.] [chattes|nom : féminin pluriel] [noires|adj. : f. pl.]
^ 3 > 1
^ 3 > 2 : accord
^ 3 > 4
legende: Le **nom commande** : toutes les flèches partent de lui. Le déterminant et les adjectifs prennent son **genre** et son **nombre**.
```

**Méthode** : je repère le nom → je regarde son déterminant (*le, la, les, un, des, mes…*) → j'accorde **tous** les adjectifs qui vont avec.

## Le pluriel des noms et des adjectifs

| Règle | Exemples |
|---|---|
| En général : **+ s** | un ami → des ami**s** · grand → grand**s** |
| Déjà terminé par **s, x, z** : on ne change rien | un bras → des bras · une noix → des noix · un nez → des nez |
| **-au, -eau, -eu** : **+ x** | un tuyau → des tuyau**x** · un bateau → des bateau**x** · un jeu → des jeu**x** (sauf : pneus, bleus) |
| **-al** → **-aux** | un cheval → des chev**aux** · normal → norm**aux** (sauf : bals, carnavals, festivals, chacals, récitals, régals) |
| **-ou** : **+ s**, sauf 7 noms en **x** | des fous, des trous… mais : bijou**x**, caillou**x**, chou**x**, genou**x**, hibou**x**, joujou**x**, pou**x** |
| **-ail** : + s, sauf quelques-uns en -aux | des rails… mais : travail → trav**aux**, vitrail → vitr**aux** |

## Le féminin des noms et des adjectifs

| Règle | Exemples |
|---|---|
| En général : **+ e** | grand → grand**e** · ami → ami**e** |
| Déjà terminé par **e** : on ne change rien | jeune → jeune · rapide → rapide |
| **-er** → **-ère** | boulanger → boulang**ère** · léger → lég**ère** |
| **-eur** → **-euse** ou **-rice** | chanteur → chant**euse** · acteur → act**rice** |
| **-eux** → **-euse** | heureux → heur**euse** |
| **-f** → **-ve** | neuf → neu**ve** · sportif → sporti**ve** |
| on **double** la consonne | gros → gro**sse** · bon → bo**nne** · gentil → genti**lle** · chien → chie**nne** |
| mots très différents | beau → belle · vieux → vieille · blanc → blanche · doux → douce |

## ⚠️ Pièges

- Adjectif placé loin du nom : *des pommes bien mûr**es***.
- Un adjectif pour deux noms : *une jupe et un pull bleu**s*** (masculin + féminin = **masculin pluriel**).


## Exercices

1. Mets au pluriel : un journal intéressant · un beau château · un caillou pointu · un gros nez
2. Mets au féminin : un voisin gentil · un vendeur heureux · un nouveau boulanger
3. Corrige : *des fleur rouge et jaune*
