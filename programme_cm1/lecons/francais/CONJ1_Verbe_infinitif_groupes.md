# CONJ1 — Le verbe : infinitif, groupes, temps simples et composés
<!-- objectifs : francais-8-5 francais-8-7 -->

## À retenir

### L'infinitif

C'est le verbe **pas conjugué**, son « nom de famille ». On le trouve dans le dictionnaire.
Pour le trouver : *« il faut … »* → *il **mange*** → il faut **manger**.

Un verbe conjugué = **radical** + **terminaison** : *nous chant**ons*** (radical *chant-*, terminaison *-ons*).

```schema phrase
colle: oui
[nous|sujet] [chant|radical|gris] [ons|terminaison]
legende: Le **radical** (gris) ne bouge pas ; la **terminaison** (rouge) change avec la personne et le temps.
```

### Les 3 groupes

| Groupe | Infinitif | Exemples |
|---|---|---|
| **1er groupe** | en **-er** (sauf *aller*) | chanter, jouer, manger |
| **2e groupe** | en **-ir**, avec **-issons** à *nous* | finir → nous fin**issons**, grandir, choisir, rougir |
| **3e groupe** | tous les autres | *aller*, être, avoir, faire, prendre, venir, partir, offrir, voir, dire… |

✅ **Le test du 2e groupe** : on dit *« nous … »* :
- *finir* → *nous fin**issons*** → 2e groupe
- *partir* → *nous partons* → **3e groupe**
- *offrir* → *nous offrons* → **3e groupe**
- *sourire* → infinitif en -**ire**, pas en -ir → **3e groupe**

```schema arbre
- Mon verbe à l'infinitif
  - finit par -er / (sauf aller) | bleu
    - 1er groupe / chanter, jouer | bleu
  - finit par -ir | vert
    - « nous …issons » / 2e groupe : finir | vert
    - pas de -issons / 3e groupe : partir, offrir | orange
  - autre fin (-re, -oir…) | orange
    - 3e groupe / prendre, voir, sourire | orange
legende: Pour trouver le groupe, je regarde la **fin de l'infinitif**, puis je fais le **test du « nous »** pour les verbes en -ir.
```


*Être* et *avoir* sont à part : ce sont des **auxiliaires** (ils aident à former les temps composés).

### Temps simples et temps composés

- **Temps simple** : le verbe est en **un seul mot** → *je chante* (présent), *je chantais* (imparfait), *je chanterai* (futur).
- **Temps composé** : **2 mots** = auxiliaire *être* ou *avoir* + **participe passé** → *j'**ai chanté*** (passé composé), *je **suis venu***.

```schema phrase
[je|sujet] [chante|1 seul mot : temps simple]
[j'|sujet] [ai|auxiliaire|violet] [chanté|participe passé|vert]
legende: Un temps **composé** a **deux mots** : l'auxiliaire (avoir ou être) et le participe passé.
```

### Les personnes

| Singulier | Pluriel |
|---|---|
| 1re : je | 1re : nous |
| 2e : tu | 2e : vous |
| 3e : il, elle, on | 3e : ils, elles |
