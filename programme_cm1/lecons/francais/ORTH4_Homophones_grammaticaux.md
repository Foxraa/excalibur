# ORTH4 — Les homophones grammaticaux
<!-- objectifs : francais-4-6 francais-7-5 -->

Des **homophones** sont des mots qui **se prononcent pareil** mais **s'écrivent différemment** et n'ont pas le même sens. Pour choisir, on utilise un **mot de remplacement**.

| Homophones | Astuce | Exemples |
|---|---|---|
| **a** / **à** | **a** = verbe avoir → je peux dire **avait** | Il **a** faim (avait ✅). Il va **à** l'école (avait ❌). |
| **et** / **est** | **est** = verbe être → je peux dire **était** ; **et** = je peux dire **et puis** | Le ciel **est** bleu **et** gris. |
| **son** / **sont** | **sont** = être → **étaient** ; **son** = à lui → **mon** | Ils **sont** dans **son** jardin. |
| **on** / **ont** | **ont** = avoir → **avaient** ; **on** = **il** | **On** dit qu'ils **ont** gagné. |
| **ou** / **où** | **ou** = **ou bien** ; **où** = le lieu, une question de lieu | Tu veux du lait **ou** du jus ? **Où** vas-tu ? |
| **ces** / **ses** | **ces** = ceux-là, on les montre (**ce**) ; **ses** = les siens, à lui (**son**) | **Ces** chaussures sont à Tom : ce sont **ses** chaussures. |
| **c'est** / **s'est** / **ses** / **ces** | **c'est** = **cela est** ; **s'est** = devant un verbe qui se fait à soi-même (*il s'est lavé*) | **C'est** mon ami. Il **s'est** blessé. |
| **ce** / **se** | **ce** = devant un nom (*ce chat*) ou **cela** ; **se** = devant un verbe (*il se lave*) | **Ce** garçon **se** coiffe. |
| **mais** / **mes** | **mais** = **pourtant** ; **mes** = à moi (**mon**) | Je cherche **mes** clés, **mais** je ne les trouve pas. |
| **la** / **l'a** / **là** | **l'a** = **l'avait** ; **là** = **ici** ; **la** = devant un nom ou = *elle* | **La** clé ? Il **l'a** posée **là**. |
| **leur** / **leurs** | devant un verbe : **leur** (invariable, = *lui*) ; devant un nom pluriel : **leurs** | Je **leur** donne **leurs** cahiers. |

## Méthode

1. Je repère le mot qui hésite.
2. Je fais le **test de remplacement** (je le dis dans ma tête).
3. Si ça marche, j'écris la bonne forme ; sinon, c'est l'autre.

```schema chaine

legende: Trois étapes, pour chaque homophone de la dictée.
```

## Exercices

Complète :
1. Mon frère … (a/à) un vélo rouge … (et/est) bleu.
2. Les enfants … (son/sont) partis avec … (son/sont) père.
3. … (C'est/S'est/Ses/Ces) la fin : Léo … (c'est/s'est) endormi.
4. Tom a perdu … (ces/ses) lunettes.
5. … (On/Ont) ira au parc … (ou/où) à la plage ?
6. Il … (la/l'a/là) mangée.

## Corrigé

1. a, et · 2. sont, son · 3. C'est, s'est · 4. ses · 5. On, ou · 6. l'a
