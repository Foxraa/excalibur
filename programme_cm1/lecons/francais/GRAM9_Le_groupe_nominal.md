# GRAM9 — Le groupe nominal (GN)
<!-- objectifs : francais-6-1 francais-6-7 francais-6-8 francais-6-9 -->

## À retenir

Un **groupe nominal** est un groupe de mots organisé autour d'un **nom** (le **nom noyau**).

> **déterminant + nom** (minimum) → *le chat*, *une maison*, *mes amis*

On peut l'**enrichir** avec des **expansions** :

| Expansion | Exemple |
|---|---|
| un **adjectif** | *un chat **noir*** / *un **petit** chat* |
| un **complément du nom** (petit mot *de, à, en, sans…* + nom) | *un verre **d'eau*** / *une robe **en coton*** / *une tarte **aux pommes*** |
| plusieurs à la fois | *un **gros** chat **noir** **aux yeux verts*** |

```schema phrase
[un|dét.] [gros|adjectif] [chat|nom noyau] [noir|adjectif] [aux yeux verts|complément du nom|violet]
^ 2 > 3
^ 4 > 3
^ 5 > 3 : ils enrichissent le nom
legende: Le **nom noyau** est au centre ; les **expansions** (adjectifs, complément du nom) viennent l'enrichir.
```

### Les déterminants

| Sorte | Exemples |
|---|---|
| articles | le, la, l', les, un, une, des, du |
| possessifs (à qui ?) | mon, ton, son, ma, ta, sa, mes, tes, ses, notre, votre, leur, nos, vos, leurs |
| démonstratifs (on montre) | ce, cet, cette, ces |
| nombres | deux, trois, dix… |

### Le nom

- **Nom commun** : *table, chien, ville* → avec un déterminant.
- **Nom propre** : *Léo, Marseille, la Seine* → majuscule.

### L'adjectif

L'adjectif **qualifie** le nom (dit comment il est). Il peut être **avant** ou **après** le nom.
Il **s'accorde** avec le nom : voir [ORTH2 — Accords dans le GN](ORTH2_Accords_dans_le_GN.md).

## Réduire un GN

On garde seulement le déterminant et le nom : *le gros chien du voisin* → *le chien*.

```schema phrase
[le|dét.] [gros|adjectif] [chien|nom noyau] [du voisin|complément du nom|violet]
[le|dét.] [chien|nom noyau]
legende: **Réduire** un GN : j'enlève les expansions, il reste le **déterminant** et le **nom**.
```

## Exercices

1. Entoure le nom noyau : a. une belle maison blanche b. le vélo de mon frère c. ces petits oiseaux bleus
2. Enrichis : *un gâteau* (avec un adjectif, puis avec un complément du nom).

## Corrigé

1. a. *maison* · b. *vélo* · c. *oiseaux*
2. Par exemple : *un gâteau délicieux* / *un gâteau au chocolat*
