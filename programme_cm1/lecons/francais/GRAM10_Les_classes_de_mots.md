# GRAM10 — Les classes de mots (nature des mots)
<!-- objectifs : francais-5-11 francais-6-2 francais-6-3 francais-6-4 francais-6-6 -->

## À retenir

Chaque mot appartient à une **classe** (on dit aussi **nature**). Elle ne change pas, comme une famille.

| Classe | Rôle | Exemples |
|---|---|---|
| **Nom** | désigne une personne, un animal, une chose, une idée | chat, Léo, joie |
| **Déterminant** | se place devant le nom | le, une, mes, cette |
| **Adjectif** | dit comment est le nom | grand, rouge, gentil |
| **Verbe** | dit ce qu'on fait ou ce qu'on est ; se conjugue | courir, être, manger |
| **Pronom personnel** | remplace un nom | je, tu, il, elle, nous, vous, ils, elles ; le, la, les, lui, leur |
| **Adverbe** | précise un verbe, un adjectif ; **invariable** | vite, bien, très, souvent, hier, ici |
| **Préposition** | introduit un complément ; **invariable** | à, de, pour, sans, avec, dans, sur, sous, chez, par, en |
| **Mot de liaison** (conjonction) | relie des mots ou des phrases ; **invariable** | et, mais, ou, donc, car, ni, or ; quand, parce que |

**Invariable** = qui ne change jamais (pas de -s, pas de -e).

```schema arbre
- Les classes de mots
  - Variables / (changent : -s, -e…)
    - nom
    - déterminant
    - adjectif
    - verbe
    - pronom
  - Invariables / (ne changent jamais)
    - adverbe
    - préposition
    - mot de liaison
legende: Deux grandes familles : les mots qui **peuvent changer** (pluriel, féminin, conjugaison) et ceux qui **ne changent jamais**.
```

```schema phrase
[Hier|adverbe] , [mon|dét.] [petit|adj.] [chat|nom] [dort|verbe] [très|adverbe] [bien|adverbe] [sur|préposition|gris] [le|dét.] [canapé|nom] .
legende: Chaque mot a sa **classe**. Les couleurs aident à les reconnaître.
```

### Les pronoms personnels

- **Sujets** : je, tu, il, elle, on, nous, vous, ils, elles
- **Compléments** : me, te, le, la, les, lui, leur, nous, vous
  → *Je vois **Léa**.* → *Je **la** vois.* / *Je parle **à Tom**.* → *Je **lui** parle.*

```schema phrase
Je vois [Léa|nom] .
Je [la|pronom] vois .
legende: Le pronom **la** remplace **Léa** pour ne pas la répéter. Attention, il se place **avant** le verbe.
```

### Les adverbes

Beaucoup se terminent par **-ment** : *lent → lentement, doux → doucement, rapide → rapidement*.

## ⚠️ Piège

Un même mot peut changer de classe selon la phrase : *le **dîner*** (nom) / *nous allons **dîner*** (verbe).

## Exercices

Donne la classe des mots en gras :
*Hier, **mon** chat **noir** a **rapidement** attrapé **une** souris **dans** le jardin, **mais** **elle** s'est échappée.*

## Corrigé

*mon* déterminant possessif · *noir* adjectif · *rapidement* adverbe · *une* déterminant (article) · *dans* préposition · *mais* mot de liaison · *elle* pronom personnel
