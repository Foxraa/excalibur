# GRAM8 — L'attribut du sujet
<!-- objectifs : francais-5-11 -->

## À retenir

Certains verbes ne montrent pas une action mais un **état**. On les appelle les **verbes d'état** :

> **être, paraître, sembler, devenir, demeurer, rester, avoir l'air**

Le mot ou le groupe qui suit un verbe d'état donne une **information sur le sujet** : c'est l'**attribut du sujet**.

- *Le ciel **est** bleu.* → *bleu* dit comment est le ciel → attribut du sujet *le ciel*.
- *Mon frère **deviendra** pompier.* → *pompier* = attribut de *mon frère*.

**Astuce** : on peut remplacer le verbe d'état par le signe **=** :
*Le ciel = bleu.* ✅

```schema phrase
[Le ciel|sujet] [est|verbe d'état] [bleu|attribut du sujet] .
^ 3 > 1 : dit comment est le ciel
[Le ciel|sujet] [=|à la place du verbe|gris] [bleu|attribut du sujet]
legende: L'**attribut** donne une information **sur le sujet**. Le verbe d'état fonctionne comme un signe **=**.
```

### L'attribut s'accorde avec le sujet

C'est souvent un **adjectif**, donc il prend le **genre** et le **nombre** du sujet :
- *La soupe est chaud**e**.* (féminin)
- *Les enfants semblent fatigué**s**.* (pluriel)
- *Les fleurs sont jolie**s**.* (féminin pluriel)

```schema phrase
[Les fleurs|sujet : féminin pluriel] [sont|verbe d'état] [jolies|attribut : -e + -s] .
^ 1 > 3 : accord
legende: L'attribut prend le **genre** et le **nombre** du sujet : *fleurs* est féminin pluriel, donc *jolie**s***.
```

## ⚠️ Piège

*Il **est** dans le jardin.* → *dans le jardin* n'est pas un attribut (on ne peut pas dire *il = dans le jardin*). C'est un complément de lieu.

## Exercices

1. Souligne l'attribut du sujet : a. Ces gâteaux paraissent délicieux. b. Ma grand-mère reste calme. c. Le lion est le roi des animaux.
2. Accorde : a. Les routes sont glissant… b. Ma voisine semble content… c. Les chats deviennent gros…

## Corrigé

1. a. *délicieux* · b. *calme* · c. *le roi des animaux*
2. a. glissant**es** · b. content**e** · c. gros (déjà terminé par -s)
