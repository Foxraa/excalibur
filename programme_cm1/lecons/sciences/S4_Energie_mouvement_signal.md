# S4 — L'énergie, le mouvement, le signal et l'information

## L'énergie

L'**énergie** permet de **faire quelque chose** : bouger, chauffer, éclairer, faire fonctionner un appareil.

### Les sources d'énergie

| Source | Renouvelable ? |
|---|---|
| **Soleil** (énergie solaire) | ✅ |
| **Vent** (éolienne) | ✅ |
| **Eau qui coule** (barrage, moulin) | ✅ |
| **Bois** (biomasse) | ✅ (si on replante) |
| **Pétrole, gaz, charbon** (énergies fossiles, formées il y a des millions d'années) | ❌ |
| **Uranium** (centrale nucléaire) | ❌ |

```schema arbre
- Les sources d'énergie
  - renouvelables / (ne s'épuisent pas) | vert
    - Soleil | vert
    - vent | vert
    - eau qui coule | vert
    - bois | vert
  - non renouvelables / (s'épuisent) | orange
    - pétrole, gaz, charbon | orange
    - uranium | orange
legende: Les énergies **renouvelables** se renouvellent sans cesse ; les autres finiront par **s'épuiser**.
```

Notre **corps** aussi a besoin d'énergie : il la tire des **aliments**.

### Les formes d'énergie

L'énergie se présente sous plusieurs **formes** et peut **passer de l'une à l'autre** :
**mouvement**, **chaleur**, **lumière**, **électricité**, énergie **chimique** (dans une pile, un aliment, l'essence).

→ *Dans une **lampe de poche** : la pile (chimique) → électricité → lumière (et un peu de chaleur).*
→ *Dans une **éolienne** : le vent (mouvement) → électricité.*

```schema chaine
Pile / énergie chimique | violet
->
Électricité | jaune
->
Lumière / (et un peu de chaleur) | orange
legende: Dans une **lampe de poche**, l'énergie **change de forme** à chaque étape.
```

## Le signal et l'information

Un **signal** transporte une **information** d'un émetteur vers un récepteur.

```schema chaine
Émetteur / le feu tricolore | gris
->
Signal / lumière rouge | rouge
->
Récepteur / le conducteur | bleu
->
Information / « je m'arrête » | vert
legende: Un **signal** voyage de l'**émetteur** au **récepteur** et lui donne une **information**.
```

| Signal | Information |
|---|---|
| feu tricolore (lumineux) | « tu peux passer » / « arrête-toi » |
| sonnerie de l'école (sonore) | « c'est la récréation » |
| clignotant d'une voiture | « je vais tourner » |
| ondes radio, Wi-Fi | le son, une vidéo, un message |

Un signal peut être **lumineux**, **sonore**, **électrique** ou transporté par des **ondes**.

## Exercices

2. Quelle transformation d'énergie se passe dans un grille-pain ?
3. Quelle est la trajectoire de la pointe d'une aiguille de montre ?
4. Quelle information donne le signal sonore d'un camion qui recule ?
