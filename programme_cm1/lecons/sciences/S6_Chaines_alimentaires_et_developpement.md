## Les besoins des végétaux

Une plante verte a besoin d'**eau**, de **lumière**, d'**air** et de **sels minéraux** (dans le sol). Avec la lumière, elle **fabrique elle-même sa nourriture** dans ses feuilles. C'est pour ça qu'on dit que les végétaux sont des **producteurs**.

## Les chaînes alimentaires

Une **chaîne alimentaire** montre **qui est mangé par qui**. La flèche veut dire **« est mangé par »**.

```schema chaine
Herbe / producteur | vert
-> est mangée par
Lapin / herbivore | orange
-> est mangé par
Renard / carnivore | rouge
legende: Une **chaîne alimentaire** : la flèche veut dire « **est mangé par** ». Elle commence toujours par un **végétal**.
```

- Une chaîne commence **toujours par un végétal** (producteur).
- Plusieurs chaînes reliées forment un **réseau alimentaire**.

- Si un maillon disparaît, toute la chaîne est perturbée.
- Les **décomposeurs** (vers de terre, champignons, bactéries) transforment les restes et les cadavres en **sels minéraux** pour les plantes : la boucle est bouclée.

```schema chaine
boucle: oui
Végétaux | vert
-> mangés par
Animaux | orange
-> restes, cadavres
Décomposeurs / vers de terre, champignons | gris
-> sels minéraux
legende: Grâce aux **décomposeurs**, ce qui meurt redevient de la nourriture pour les plantes.
```

## Le développement des animaux

- **Ovipares** : les petits naissent d'un **œuf** pondu (oiseaux, poissons, insectes, reptiles).
- **Vivipares** : les petits se développent **dans le ventre de la mère** (la plupart des mammifères).

Certains animaux changent de forme en grandissant : c'est la **métamorphose**.
```schema chaine
boucle: oui
œuf | jaune
->
chenille | vert
->
chrysalide | orange
->
papillon | violet
-> pond
legende: La **métamorphose du papillon**.
```

```schema chaine
boucle: oui
œufs | jaune
->
têtard / (dans l'eau) | bleu
->
grenouille | vert
-> pond
legende: La **métamorphose de la grenouille** : le têtard respire dans l'eau, la grenouille respire à l'air.
```

## La reproduction des plantes à fleurs

1. La **fleur** est **pollinisée** (le pollen est transporté par le **vent** ou les **insectes**, comme l'abeille).
2. La fleur se transforme en **fruit**, qui contient des **graines**.
3. La graine est **dispersée** (vent, animaux, eau).
4. Elle **germe** dans la terre et donne une nouvelle plante.

```schema chaine
boucle: oui
Fleur | violet
-> pollinisation (abeille, vent)
Fruit / avec des graines | rouge
-> dispersion
Graine dans la terre | orange
-> germination
Nouvelle plante | vert
->
legende: Le **cycle de vie d'une plante à fleurs**.
```

Certaines plantes se reproduisent aussi **sans graines** : bouture, stolons (fraisier), bulbes (tulipe).
