## Se présenter

| Question | Réponse |
|---|---|
| **What's your name?** | **My name is** Léo. / **I'm** Léo. |
| **How old are you?** | **I'm nine** (years old). |
| **Where do you live?** | **I live in** Marseille, **in France**. |
| **Where are you from?** | **I'm from** France. **I'm French.** |
| **When is your birthday?** | **My birthday is in** May. |

## Les consignes de classe *(vu en période 1)*

| Anglais | Français |
|---|---|
| **Listen!** | Écoute ! |
| **Repeat!** | Répète ! |
| **Look!** | Regarde ! |
| **Read!** | Lis ! |
| **Write!** | Écris ! |
| **Sit down! / Stand up!** | Assieds-toi ! / Lève-toi ! |
| **Open / Close your book!** | Ouvre / Ferme ton livre ! |
| **Be quiet!** | Silence ! |
| **Raise your hand!** | Lève la main ! |
| **Can I go to the toilet, please?** | Est-ce que je peux aller aux toilettes, s'il vous plaît ? |
| **I don't understand.** | Je ne comprends pas. |
| **Please / Thank you** | S'il te plaît / Merci |

3. Traduis : *Lève la main !* · *Je ne comprends pas.*
